# Land in Korea 호스트 캐릭터 시트

모든 카드뉴스·이미지·영상에서 이 외모를 그대로 재사용한다. 설명을 바꾸거나 새 외모를 만들지 않는다.

## 외모 스펙

- 한국인 남성, 20대 후반
- 키 약 180cm, 65kg, 마른 러너 체형(벌크 아님)
- 사이드스윕 다크헤어, 깔끔한 턱선
- 얇은 검은색 원형 안경
- 오른쪽 눈 밑 작은 애교점
- 차분하고 자신감 있는 미소(장난스럽지 않게)

## 의상 (고정)

- 크림/화이트 셔츠 + 차콜 또는 네이비 블레이저
- **겨자색(mustard-yellow) 스카프는 모든 이미지에 반드시 포함** (브랜드 컬러 포인트)

## 포즈·톤

- 다큐멘터리 리포터나 문화 전문가처럼 설명하는 제스처
- 직접적인 시선, 차분한 권위감
- 딱딱한 스톡사진 모델 느낌은 금지
- 배경은 경복궁 등 한국 랜드마크·한옥 거리 활용

## 생성 규칙

- 새 이미지를 만들 때는 위 레퍼런스 중 하나를 `imageReferences`로 함께 넘겨 일관성을 유지한다.
- 무료 경로: Canva `generate-image`. Higgsfield 이미지·영상 생성은 무료 플랜에서 막혀 있으며, 유료 결제는 사용자 승인 후에만 진행한다.
- 말하는 영상(립싱크)은 Higgsfield 유료 플랜이 필요하므로 보류 상태다.
- 실제 인물 사진이나 특정 실존 인물과 닮게 만들지 않는다. 이 캐릭터는 가상 호스트다.

## 사용 위치

- 인스타·스레드 카드뉴스 표지 또는 마지막 컷 (정지 이미지 호스트)
- 블로그 저자 프로필 사진 (현재 사이트에는 아직 없음, 게시 전 사용자 확인 필요)
